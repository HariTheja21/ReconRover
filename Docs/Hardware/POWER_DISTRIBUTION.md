# Recon Rover V1 — Power Distribution Architecture

**Document Version:** 1.0  
**Status:** Frozen Specification  
**Last Updated:** 2026-06-28  

This document specifies the power rails, voltage regulation, and current budgets for Recon Rover V1. A strict dual-rail 5V design is used to isolate the cognitive layer (Raspberry Pi) from the electrical noise generated by the reactive layer (Motors, Servos, LEDs).

## 1. Main Power Source

| Component | Specification | Notes |
|-----------|---------------|-------|
| **Battery** | 2S Li-Po (7.4V Nominal) or 3S Li-Po (11.1V) | 2S is recommended for optimal L298N logic/motor balance. |
| **BMS** | Battery Management System required | Must provide over-discharge (<6.0V for 2S), overcharge, and overcurrent protection. |
| **Main Switch**| Rated for 10A+ | Placed immediately after the BMS. |

## 2. Power Rails

The system splits the main battery voltage into three separate electrical domains.

### Rail A: Cognitive Domain (5.0V)
* **Source:** 5V Buck Converter #1 (High-quality, low-ripple).
* **Consumers:**
  * Raspberry Pi 3B+
  * USB Webcam
  * USB Microphone
* **Why Isolated?** Prevents CPU voltage sag and SD card corruption when servos or motors stall.

### Rail B: Reactive Domain (5.0V & 3.3V)
* **Source:** 5V Buck Converter #2.
* **Consumers (5V):**
  * ESP32-S3 (VIN pin)
  * SG90 Pan & Tilt Servos
  * WS2812B ARGB LED Strips
  * HC-SR04 Ultrasonic Sensors
  * MQ-2 Gas Sensor
* **Consumers (3.3V):** *(Supplied by ESP32 internal LDO)*
  * SSD1306 OLED Displays
  * VL53L0X ToF Sensors
  * MPU6050 IMU
  * PCA9548A Multiplexer

### Rail C: Motive Domain (Raw VBAT)
* **Source:** Direct from BMS output (unregulated).
* **Consumers:**
  * L298N Motor Driver Logic & Output Stage
  * 4x DC Gear Motors
* **Why Unregulated?** Motors draw high stall currents that would overwhelm standard buck converters. The L298N steps this down effectively for motor drive.

## 3. Power Distribution Diagram

```text
[ Battery Pack ] ---> [ BMS ] ---> [ Main Switch ]
                                        |
    +-----------------------------------+-----------------------------------+
    |                                   |                                   |
[ Buck #1: 5V ]                   [ Buck #2: 5V ]                       [ Raw VBAT ]
    |                                   |                                   |
    +-> Raspberry Pi 3B+                +-> ESP32-S3 VIN                    +-> L298N ENA/ENB
    +-> USB Webcam                      +-> SG90 Servos                     +-> DC Motors
    +-> USB Microphone                  +-> WS2812B LEDs
                                        +-> HC-SR04 / MQ-2
```

## 4. Grounding

All domains (Rail A, Rail B, Rail C) **must share a common ground**. If grounds are not tied together, logic level signals (like the serial JSON bridge or PWM lines) will float and fail to communicate.
